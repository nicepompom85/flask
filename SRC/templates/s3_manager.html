AWS 認證金鑰未配置（本地開發模式）

本專案沒有硬編碼任何 AWS 存取金鑰，以確保程式碼安全。這符合在生產環境（如 EC2）使用 IAM Role (Instance Profile) 的安全規範。

在本地環境開發時，請使用以下任一安全的方法來配置 AWS 憑證以進行存取：

方法 A：使用 AWS CLI 配置（推薦）

在您的終端機執行以下指令並輸入金鑰，boto3 將會自動讀取產生的設定檔：

aws configure

方法 B：配置環境變數

如果您是在 Windows PowerShell 中開發，可以設定臨時環境變數：

$env:AWS_ACCESS_KEY_ID="您的AccessKey" $env:AWS_SECRET_ACCESS_KEY="您的SecretKey" $env:AWS_DEFAULT_REGION="ap-northeast-1"

方法 C：Docker 容器運行掛載

如果您是在 Docker 內運行，可以將本地的 .aws 目錄掛載至容器中：

docker run -p 19191:19191 -v ~/.aws:/root/.aws:ro flask-dashboard
